# TinyTangyuan BLOOM｜小湯圓・花開日記

A playable browser prototype based on the TinyTangyuan game design brief.

## Prototype features
- 🌱 Simulated walking loop and step counter
- 🌸 Plant flowers on the map
- 📍 Discover locations: park, station, seaside, shop
- 🌱 Collect TinyTangyuan sprouts
- 📖 Auto-generated daily diary
- 🏡 TinyTangyuan home / memory collection
- 📍 Optional browser geolocation display
- 💾 Progress saved locally with `localStorage`
- 📱 Responsive desktop/mobile layout

## Run
Open `index.html` in a browser, or publish the `tiny-tangyuan-bloom` folder through GitHub Pages.

The prototype intentionally uses original HTML/CSS/JS and emoji-based placeholders, so it does not depend on third-party game assets.
